# Programa para solicitar ao usuário nome do cliente, preço do produto e seleção de desconto entre as opções apresentadas e então é mostrado o valor final com desconto que o cliente pagará.

Programa que solicita ao usuário nome do cliente, preço do produto e seleção de desconto entre as opções apresentadas e então é mostrado o valor final com desconto que o cliente pagará.

Desenvolvido utilizado JDK 1.8 e NetBeans 13.
